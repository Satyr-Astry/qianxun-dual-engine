# 论文规划 · MemState: What Does a 0.3% Architectural Add-On Actually Buy You?
> 定位：**A 号产出物之三**。本文件是论文骨架（不写正文，先钉死**可辩护的主张**与**证据表**）。
> 作者：Satyr_Astry　｜　首个实质版本：2026-09-24

---

## 0. 一句话
我们在一台 12GB 单机上，用**严格可复现的实验工装**检验"**冻结主干 + 极小架构件（0.3%）**能否给 LLM 装上可写可读的分层记忆"，
给出**否定的实测答案**，并公开**为什么容易得出假阳性结论**（三条陷阱：零死锁的等价性盲区、抽样 hash 假警报、小样本单种子噪声）。

## 1. 贡献（每条都必须有实测证据撑住）
| # | 主张 | 证据 | 强度 |
|---|---|---|---|
| C1 | **零门挂载可实现"结构等价改写"的逐位无损**：新架构骨架可以套在现有权重上而不改变任何一位输出 | 逐 token 100.00%、logits maxdiff 0.000e+00（Qwen2.5-1.5B-Instruct，fp32，同设备） | ✅ 强（可复现，门槛可核） |
| C2 | **等价性测试对"零死锁"是盲的**，必须配 init 梯度体检（`∂L/∂gate`）——否则会得到"改造成功但分支永不激活"的假通过 | N1 首版：等价 100% 但 gate 恒 0、`∂L/∂gate=0`；修正后 gate 0→±0.062 | ✅ 强（含对照） |
| C3 | **"写入只进记忆、不进主干"在工程上成立**：9 轮训练后主干张量 max-abs-diff 恒为 0.000e+00 | N2c/N2d/N2e 全部轮次 | ✅ 强（张量级全量比对） |
| C4 | **但"记忆分支带来关联召回增益"未被证实**：128 键 × 2 种子下净贡献 **−1.0 pp**；多深度注入、难度刻度（2 位码）均无稳定正增益 | N2d 四组 × 多种子 | ✅ 强（负结果，样本足） |
| C5 | **Titans 式运行时动态写入在本机预算下"实现未过关"**：loss 曲线不稳（4.73→8.30→3.54）、召回 0% | N2e | ⚠️ 中（属实现级，非原理级） |
| C6 | **三条"假阳性陷阱"清单 + 一套可复用检查工装**（等价性/梯度体检/张量级不变性/负对照协议/独立显存口径/多种子记录） | `tools/memcore_harness.py` + `--selftest` 全 PASS | ✅ 强（工装可自测） |

**结论口径务必保守**：本文主张的是"**在单机小预算档位下，冻结主干 + 0.3% 架构件不足以建立可写可读记忆**"，
**不是**"忆态架构原理错误"，更**不是**"记忆层无用"（Memory Layers 在大规模联合训练下已有正向结果）。

## 2. 与已有工作的关系（诚实定位）
| 工作 | 它们做了什么 | 本文的差异 |
|---|---|---|
| Memory Layers（Meta, 2412.09764） | 1M 条目在 1.3B 底座上把 NQ EM 7.76→13.68；**联合训练整模型，1T token** | 我们问的是它们的**低预算退化版**是否成立 → **答：不成立**（这是我们唯一的"新"） |
| Sparse Upcycling（2212.05055） | 把 dense 升成 MoE，**续训 ~50% 原始预算** | 同上：我们把"省算力期望"这件事**实测掉了** |
| Titans（2501.00663）/ TTT | 测试时更新记忆状态 | 我们做了低预算复现尝试（N2e）→ **未过关**，给出实现级的失败模式 |
| 各类 spec-decoding / KV 量化 | 在**不改架构**的前提下拿 1.2–1.8× | 属本项目的过渡工具链（路线 C），与本论文互补 |

## 3. 实验矩阵（全部可复现）
| 编号 | 被试 | 设置 | 主指标 | 状态 |
|---|---|---|---|---|
| N1/S0 | Qwen2.5-1.5B fp32 | 零门挂载 3 层记忆分支 | 逐 token 一致率 / logits maxdiff / gate 梯度 | ✅ 100.00% / 0.0 / 活 |
| N2 | 同上 | 静态池写入（**错误格式**：事实在上下文内） | 召回 | ❌ 0%（设计错误，已修正） |
| N2b | 同上 | 查询式训练 + 留出键负对照 | 召回 | ❌ 0% |
| N2c | 同上 | 三臂：只记忆 / 记忆+读出侧 / 只有读出侧 | 召回 + 张量级主干 diff | 9.4% vs 3.1%（**后证为噪声**） / 0.0 |
| N2d | 同上 | 128 键 × 2 种子；多深度注入；2 位码难度刻度 | 召回（4 组） | ❌ 净贡献 −1.0pp |
| N2e | 同上 | Titans-lite 动态写入（留出键推理时写入） | 留出键召回 | ❌ 0%，loss 不稳 |
| N5（待） | Qwen3-14B 分层加载 | 14B 上的结构等价改写 | 逐 token / maxdiff | ⏳ 未做（12GB 需分层） |
